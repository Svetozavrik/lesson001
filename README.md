Дипломный проект: Автоматизация тестирования Skyeng
Данный проект представляет собой автоматизацию тестирования личного кабинета преподавателя Skyeng. 
Проект разработан в рамках дипломной работы по курсу "Автоматизация тестирования на Python".
Что тестируется:
UI-тесты: Проверка интерфейса и основных элементов страниц
API-тесты: Проверка доступности эндпоинтов и работы с событиями


Python 3.14+
pytest -для тестирования
Selenium WebDriver-для UI-тестов
Requests- для API-тестов
Allure-для отчетов
Flake8- для проверки стиля кода


Структура проекта:
diplom/
conftest.py # Фикстуры и тестовые данные
pytest.ini # Настройки pytest
requirements.txt # Зависимости
test_api.py # 5 API тестов
test_ui.py # 5 UI тестов
README.md # Документация

UI тесты
`test_main_page_load`  Проверка загрузки главной страницы 
`test_page_title` Проверка заголовка страницы 
`test_main_elements`  Проверка наличия основных элементов (ссылки, кнопки) 
`test_schedule_page`  Проверка загрузки страницы расписания 
`test_page_has_form`  Проверка наличия форм на странице 
API тесты 
`test_create_personal_event`  Создание личного события через API 
`test_create_math_lesson`  Создание урока по математике через API 
`test_edit_event`  Редактирование события через API 
`test_delete_event`  Удаление события через API 
`test_create_past_event`  Негативный тест: создание события в прошлом 

Установка зависимостей
pip install -r requirements.txt

 Запуск только UI-тестов
pytest -m ui -v

Запуск только API-тестов
pytest -m api -v

Запуск конкретного файла
pytest test_ui.py -v
pytest test_api.py -v

Проверка стиля кода
flake8 .
